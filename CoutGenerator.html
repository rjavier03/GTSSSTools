Distribution logic

If you request 20 cout statements, the tool:

1. Finds all valid insertion points in Translation::translate().
2. Finds functions called by translate().
3. Recursively finds subfunctions called by those functions.
4. Collects all valid insertion points from the entire reachable program.
5. Spreads the requested cout statements across those points.
6. Uses sequential numbering: test 1, test 2, test 3, ... test 20.

Protected control flow

The tool will NOT insert cout:
• Between if and its body.
• Between else if and its body.
• Between else and its body.
• Between an if block and its else.
• After return.
• After break.
• After continue.
• Outside Translation::translate() and its reachable subfunctions.
